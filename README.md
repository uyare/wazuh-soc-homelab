# SOC Home Lab: Endpoint Monitoring, Threat Detection, and Automated Response with Wazuh & Sysmon

## 📝 Objective

The objective of this project is to build a functional Security Operations Center (SOC) home lab to monitor endpoint telemetry, detect threats, and execute automated responses. This environment utilizes Wazuh as the SIEM/XDR platform to ingest and analyze logs generated by Sysmon across Windows and Linux endpoints. The project demonstrates practical skills in detection engineering, File Integrity Monitoring (FIM), MITRE ATT&CK mapping, Security Orchestration, Automation, and Response (SOAR), and compliance auditing.

## 🛠️ Tools & Technologies Used

- **Hypervisor:** VirtualBox
- **SIEM / XDR:** Wazuh (Manager & Dashboards)
- **Endpoint Telemetry:** Sysmon (Windows) & Sysmon for Linux
- **Configurations & Scripts:** SwiftOnSecurity Sysmon config, HardeningKitty
- **Query Languages:** Wazuh Query Language (WQL), OpenSearch Dashboards Query Language (DQL)
- **OS:** Windows 10, Amazon Linux 2023, Ubuntu 22.04
- **Security Concepts:** FIM, SCA, CIS Benchmarks, Active Response (SOAR), MITRE ATT&CK

## 🏗️ Architecture & Lab Setup

- **Manager:** Wazuh VM (Hosted on Amazon Linux 2023)
- **Agent 1:** Windows 10
- **Agent 2:** Ubuntu 22.04

## ⚙️ Project Walkthrough & Configuration

### 1. Establish Telemetry and Visibility

_Default Windows logs are rarely enough for a SOC. High-fidelity telemetry is required to detect modern threats._

- **Agent Deployment:** Installed and started Wazuh agents on both Windows 10 and Ubuntu 22.04.
- **Sysmon Integration:** Installed Sysmon on Windows using the **SwiftOnSecurity** configuration file to capture granular process creation (Event ID 1) and network connections (Event ID 3). Installed Sysmon for Linux on the Ubuntu endpoint.
- **Log Ingestion:** Modified the Wazuh Agent `ossec.conf` file on both endpoints, adding the Sysmon event channels to the `<localfile>` block to ensure Wazuh ingests these advanced logs. Restarted services to initiate forwarding.

### 2. Configure File Integrity Monitoring (FIM)

_FIM is a core compliance requirement (PCI-DSS, HIPAA) used to catch unauthorized changes and ransomware activity._

- **Target Setup:** Created a sensitive directory on the Windows VM at `C:\Finance_Data`.
- **Wazuh Config:** Added a `<directories check_all="yes">C:\Finance_Data</directories>` block to the Windows Agent `ossec.conf`.
- **Validation:** Created, modified, and deleted files within the directory. Verified that the File Integrity Monitoring events successfully triggered and were displayed correctly in the Wazuh dashboard with detailed change information.

### 4. Automate Defense with Active Response (SOAR)

_Leveraging Active Response to instantly contain threats without manual analyst intervention._

- **Trigger Configuration:** Configured Wazuh to automatically block an attacker's IP address if they fail to log in 5 times within a 2-minute window.
- **Wazuh Config:** Edited the Wazuh Manager `ossec.conf` to utilize the default `firewall-drop` script within the `<command>` block, and set the `<active-response>` block to trigger on the Rule ID associated with RDP brute-forcing.
- **Validation:** Executed the RDP brute-force attack from the host machine. Verified that the host IP was automatically blocked by the Windows firewall and checked the Wazuh Active Response logs to confirm the automation fired successfully.

### 5. Security Configuration Assessments (SCA) & Hardening

_Proactively hardening systems against vulnerabilities before attacks occur._

- **Baseline Audit:** Reviewed CIS (Center for Internet Security) Benchmarks for Windows inside the Wazuh SCA dashboard.
- **Vulnerability Simulation:** Intentionally weakened the Windows VM by enabling the Guest account, disabling the Windows Firewall, and turning off password complexity. Forced an SCA scan and documented the compliance score drop.
- **Remediation:** Fixed the created vulnerabilities and utilized **HardeningKitty** to enforce secure configurations. Rescanned the endpoint to document a significantly improved compliance score.
